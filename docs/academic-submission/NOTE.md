# Academic submission (preserved)

This folder holds the original DA510 Assignment 2 submission exactly as it was
graded: the assignment brief, report, demo deck, demo script, screenshots and
the scripts that generated them. The original README is kept here as
`README.md`.

The code as submitted is frozen at the Git tag **`v1.0-academic`**:

```bash
git checkout v1.0-academic
```

The build scripts (`build_report.py`, `build_deck.js`, `make_diagram.py`) use
paths relative to the repository root as it was laid out at that tag, so run
them from a checkout of the tag rather than from this folder.

Everything outside this folder is the independent engineering work that
followed the course. See [`docs/ROADMAP.md`](../ROADMAP.md).
